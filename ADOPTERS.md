# Adopters

This file lists the organizations and projects known to be using
`iec61850-rust`. It exists so that a reader evaluating the implementation can
see where it has actually been exercised — which protocol roles, on what kind of
equipment, at what scale.

Being listed is entirely voluntary and confers nothing: the project is free to
use in any setting, commercial deployments included, and no registration,
notification or permission is required. There is no tier, no logo program and no
obligation attached to an entry.

To add yourself, open an issue using the
[adopter template](.github/ISSUE_TEMPLATE/adopter.md), or open a pull request
editing this file. If you would rather ask something before deciding, start a
GitHub Discussion.

What an entry needs: an organization or project name, one line on what it is
used for, and which protocol roles are in play — client, server, GOOSE
publisher or subscriber, Sampled Values publisher or subscriber, SNTP. A contact
is optional; leave the column empty if you would rather not name anyone. Do not
list anything that is not yours to disclose. An entry can be removed at any time
by opening an issue asking for it.
